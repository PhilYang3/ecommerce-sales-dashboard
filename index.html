使用说明
1. 每日录入流程
切换到"数据录入"页 -> 选择日期 -> 填写9个平台数据 -> 点击"保存当日数据"
2. 查看看板
切换到"数据看板"页 -> 选择日期范围 -> 点击"刷新看板" -> 图表自动更新
3. 数据备份与迁移
在"数据录入"页点击"导出CSV"可下载全部数据；换电脑时用"导入CSV"恢复
4. 数据存储位置
数据存储在浏览器 localStorage 中，清除浏览器缓存会导致数据丢失，请定期导出备份
5. 多人协作方案
数据源自动从腾讯文档读取，生成 data.json 随看板一起部署到云端。团队成员打开链接即可查看最新数据，无需各自导入
数据云端共享
数据来源于腾讯文档 Y26 电商看板数据源，每次部署时自动同步最新数据。如需更新数据，编辑腾讯文档后告知 AI 助手重新部署即可。
云端数据为只读模式，如需本地离线使用，可导出并手动导入
指标口径定义
GMV
消费者已支付订单金额（含运费，不含退款）
去退GMV
GMV - 退款金额，看板中所有 GMV 相关指标均以此口径计算
订单量
已支付的订单总数（含退款订单）
访客 UV
去重后的独立访客数，取各平台官方后台数据
新客数
当日首次在本平台下单的用户数
推广费用
当日花费的付费推广费用（直通车/引力魔方/千川/多多搜索等）
ROI
去退GMV / 推广费用。衡量推广投入产出比，ROI越高代表推广效率越好
费效比
推广费用 / 去退GMV x 100%。费效比越低代表推广成本占比越低
周期环比
N天的汇总数据对比前N天，选1天即单日环比，选7天即周度环比
月度目标设置
设置每月各平台的去退GMV目标，用于计算月至今达成率。进度周期规则：每月27日起进入次月追踪（如8/27起追踪9月目标），月至今周期=当月27日至昨日（今日数据通常未完整）。
